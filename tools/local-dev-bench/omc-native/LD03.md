# OMC LD03 shared-value replay

Generate either canonical LD03 family and validate against observations from an installed native service.

```sh
python3 tools/local-dev-bench/workloads/synthetic.py fixture LD03 --variant field-relay > /path/to/fixture.json
node --test tools/local-dev-bench/omc-native/ld03.test.mjs
node tools/local-dev-bench/omc-native/ld03.mjs --fixture /path/to/fixture.json --fixture-only
node tools/local-dev-bench/omc-native/ld03.mjs --fixture /path/to/fixture.json > /path/to/observations.json
python3 tools/local-dev-bench/workloads/synthetic.py grade LD03 /path/to/observations.json --variant field-relay
```

The replay runs headless in a temporary profile using the installed product service. `OMC_BENCH_BIN_DIR` may identify a different candidate's folder. The timed edit consists of two FigCraft variable writes. Setup, save, normal service restart, readback, and two verification writes on a native duplicate each appear under separate boundaries. Use the canonical grader to decide whether all phases passed.

Each normalized capture requires all observed nodes, stable canonical IDs, raw token references and literal overrides. FigCraft catalog reads verify token values. The renderer's resolved fill inspection and sibling distance queries verify fill and gap independently of the authored properties. The replay reads the original again after changing the native duplicate. This service diagnostic leaves physical presentation, native component extension, model usage and resource measurement outside its scope.
