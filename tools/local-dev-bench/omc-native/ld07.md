# Installed OMC LD07 defect repair

Set `OMC_LD07_EVIDENCE` to a fresh evidence directory under the primary checkout's private `internal/docs/`. Set `OMC_LD07_VARIANT` to `transit-departures` or `clinic-check-in`. Run from the measurement checkout.

```sh
mkdir -p "$OMC_LD07_EVIDENCE"
PYTHONDONTWRITEBYTECODE=1 python3 tools/local-dev-bench/workloads/synthetic.py fixture LD07 --variant "$OMC_LD07_VARIANT" > "$OMC_LD07_EVIDENCE/fixture.json"
node tools/local-dev-bench/omc-native/ld07.mjs --fixture "$OMC_LD07_EVIDENCE/fixture.json" --artifact-dir "$OMC_LD07_EVIDENCE" > "$OMC_LD07_EVIDENCE/observations.json"
PYTHONDONTWRITEBYTECODE=1 python3 tools/local-dev-bench/workloads/synthetic.py grade LD07 "$OMC_LD07_EVIDENCE/observations.json" --variant "$OMC_LD07_VARIANT" --symptom-screenshot "$OMC_LD07_EVIDENCE/symptom.png" > "$OMC_LD07_EVIDENCE/grade.json"
```

The installed service uses an isolated temporary profile. The replay creates an editable board, injects the registered defects, and writes a native PNG before diagnosing them. Transit uses wrapping and a fill binding. Clinic uses the row gap and a shared token value that changes both bound badges. The replay records the whole-document response and reads the affected node subtrees or token catalog. It repairs the two properties, and verifies the saved result after a normal service restart. The PNG measures software raster output. The replay records deterministic phase timing. Physical presentation, model use, and resource use are unmeasured.

Pass `--fixture-only` to check the fixture projection without launching the service. Run the offline checks with `node --test tools/local-dev-bench/omc-native/ld07.test.mjs`.
