# Paper conservation atlas plan

The neutral LD02 fixture in `../workloads/ld02.py` has ten pages, four
zones per page, and 1,000 editable shapes and text nodes. It uses a
title and receipt together for discovery. The legacy Paper replay
continues to exercise its separate returns fixture.

## Candidate workflow

1. Prepare a disposable document with the ten fixture pages outside the
   timed attempt. Use explicit file and page IDs with `create_page` and
   `write_html`. Preserve each station's five editable children, native
   column layout, and three starting properties. Preserve official native
   IDs in an observer-only manifest. Confirm empty selection with
   `get_selection` before starting.
2. Give the measured agent only the public LD02 brief and disposable
   document. Use `find_nodes` on both exact visible text values and
   `get_node_info` to match their actual parent. Locate the status and
   condition marker through scoped tree reads. Keep discovery and
   verification distinct in the trace.
3. Send `set_text_content` for the identified status, then
   `update_styles` for the identified gap and radius properties. Read
   all ten pages back independently and retain the native IDs, logical
   node names, tree relationships, and link from each read to its file.
4. Capture a real close/reopen and run native Undo/Redo on a separate
   verification copy of the starting document. The adapter can use
   `create_file` with its observed `cloneFileId` property when the
   approved source contains only test material and an explicit
   destination is registered. An already-open file and a newly
   connected MCP client leave the editor in the same state.

## Remaining capability evidence

The installed MCP schema exposes a read for selection and no clear
selection, file close, Undo, or Redo action. Leave attempts incomplete
if the normal editor actions and their state changes cannot be observed.
MCP writebacks of previous values cannot satisfy the native history
requirement. File cloning creates a separate document. The destination's
availability without opening an editor tab needs an explicit check.

`get_node_info` gives no resolved positions for some flow children on
inactive pages. The observer must obtain actual child geometry before
grading every page. A stable inline-style export is useful supplementary
evidence. Its authored positions and application-independent browser
layout do not by themselves establish actual Paper geometry. The primary
condition remains unqualified while these readbacks, native history,
and normal reopen are missing.
