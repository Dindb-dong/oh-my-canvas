# Figma LD05 source and canvas handoff

Use a dedicated synthetic Draft. Keep the source checkout and approved Figma
file fixed across all three scheduled patches. Generate the neutral fixture and
apply the source steps with `ld05_contract.py` and `ld05_source.py`.

The executable deterministic route is `ld05-run.mjs FAMILY ATLAS_SCOPE_JSON`
under `run_attempt.py`. The scope must come from an independently verified
approved personal Atlas Draft. The runner adds one uniquely named recovery page,
materializes browser-observed source data and styles into editable native layers,
retains existing card IDs across refreshes, performs the actual native edits,
and reads each stage through a second official connector. It commits source
patches and handoffs in its isolated source checkout and checks clean copies at
all three widths. The emitted candidate omits unobserved normal editor reopening,
so the shared grader retains that failure. This route uses deterministic native
reconstruction, and carries no model-token claim.

1. Run the patched local application and exercise the registered keyboard,
   validation and list states in an isolated browser. Use the official
   `generate_figma_design` capture for those source views in the same Draft.
   Keep its actual capture receipts. Bind editable native card and list IDs
   from the observed capture. Record any layer identity changes across refresh.
2. Pass the observed native scope and action to `planLD05NativeCycle`. It
   generates paired `edit` and independent `read` requests for official
   `use_figma`. The scope includes the actual page, frame, auto-layout list,
   card and heading IDs, plus the variant detail and image IDs for cycle three.
   Supply the image hash from the registered original's actual upload.
3. Close and reopen the file normally in an authenticated isolated editor.
   Submit the independent native read again after reopening. Use
   `mergeLD05NativeHandoff` to carry only the confirmed native changes into the
   previous source checkout. It checks native IDs, common design values and
   the exact returned image bytes before merging.
4. Rebuild from a clean copy, run the shared three-width behavior probe, keep
   source lineage and content hashes, and feed actual observations to the
   independent LD05 contract grader. Carry the accepted checkout into the
   next cycle.

The Node tests exercise native operations and source merging with a mocked
Figma runtime. The official capture route, editor lifecycle, three-width
verification and full product result require live evidence.
