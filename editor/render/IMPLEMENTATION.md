# Independent rendering, layout, fonts, and rendered export

## Authorship and inputs

These modules were independently written in the B implementation lane. Inputs were `editor/contracts.ts`, `docs/independent/contracts.md`, the independently worded behavior inventory and parity manifest, the new sibling-lane APIs, browser DOM/SVG/Canvas/FontFace APIs, and the installed `canvaskit-wasm` 0.42.0 public TypeScript declarations. The machine defaults and the original host's package/TypeScript configuration and bundled font manifest were read. No inherited editor source, inherited paint wrapper, copied test bodies, or other Leviosa implementation was read or used as a template by this lane. Other planning/implementation participants have recorded source exposure; this is not an unexposed clean-room claim or a legal clearance statement.

Boolean operands remain editable in the document. The renderer maintains a derived geometry projection from current operands and exposes accurate tight bounds without introducing an extra history operation. Exports await this computation. Resource deadlines reject unsettled rendering; image/font failures are retained as explicit diagnostics. Waiting uses bounded timers rather than relying on animation frames from foreground windows.

## Shared helpers

- `render/index.ts`: `shapePath`, `boundsOf`, `textHTML`, `SceneWriter`, `combinePaths`, and the `SceneOptions`/`TextFragment` types.
- `combinePaths(shapes, operation, {wasmUrl?, objects?})` resolves to `{segments, fillRule, bounds}`. `objects` preserves nested/grouped operand semantics.
- The render view additionally exposes `sceneSvg(ids?, options?)`, `textLines(id)`, `textSize(id)`, `bounds(ids)`, `projectedShape(id)`, and `onRender(listener)`.
- `layout/index.ts`: `applyLayout(doc, before?, options?)` mutates only the caller's isolated candidate; `measureTextLayout(shape, options?)` returns width/height/scroll extents and an actual browser inline baseline.
- Font catalog additionally exposes `ensure(text, family?)` and `embeddedCss()`.

## Validation and limits of current evidence

Strict standalone TypeScript checks of all four lane entry points pass. No replacement regression test was authored or run in this lane before the parent's implementation-complete barrier. Runtime browser/Electron comparisons, image/PDF decoding, visual paint parity, loaded-font line metrics, background-window capture, and resource-lifetime evidence remain the later regression gate; static implementation is not a claim that those checks passed.

Angular/diamond paint is sampled into 256-pixel gradient tiles. Corner smoothing uses a continuous cubic approximation. Rational conics are subdivided until sampled cubic deviation is at most 0.000001 world units (with an explicit failure if the recursion bound is reached). These numerical/rendering choices require the independent visual/geometric acceptance checks; they are not asserted identical to the inherited rasterizer's antialiasing. Exporting font bytes requires the configured local/cross-origin font source to be readable; a failed fetch rejects export rather than silently replacing typography. Extremely large raster dimensions reject the browser canvas limit instead of emitting a fake or truncated file.

Native save cancellation/write errors are propagated by the host adapter and must be exercised through the actual desktop shell after integration. Optional paid/cloud providers are not configured or claimed available. No source or artifact was uploaded, and no commit was made by this worker.

## Pre-barrier static review corrections

A subsequent read-only pass found four real implementation defects and they were corrected before regression authorization: independent legacy rectangle clipping no longer uses the clipped layer's path/ellipse geometry (local and world clips prevent double orientation); flex baseline alignment uses the actual native inline baseline for fixed and auto text; reversed flex axes preserve original line grouping and reverse the main-start/main-end anchors; vector text/group masks use white glyph/descendant geometry with paint opacity, effects, and image alpha excluded. These corrections pass the lane TypeScript check. They still require independent dynamic cases after the barrier.
