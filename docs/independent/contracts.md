# Frozen integration contract

Inputs: independently worded source-observed behavior inventory and existing original host interoperability boundaries. Source-exposed planning; no clean-room claim. No old algorithms, implementations or test bodies belong in new modules.

## Module entry points (exclusive owners)

- A: `editor/document/index.ts` exports `Editor` implementing contracts.EditorStore, `createDocument`, `createShape`, `validateDocument`, tree helpers. `editor/geometry/index.ts` exports geometry/viewport helpers including `screenToWorld`, `worldToScreen`, `boxGeometry`; coordinates are world-space. `editor/commands/index.ts` exports `createCommands(editor,services)` and all document/path/clipboard command implementations. Editor transactions use isolated candidates, one commit event, rollback on errors; nested commands join the current transaction. begin/preview/commitSession/cancelSession handle gesture/text local state; operation ID/label survive to host. Provide state cleanup and history, page/tree operations and all required command IDs. A may add pure submodules only within owned directories.
- B: `editor/fonts/index.ts` exports `createFontCatalog(faces,options)`; `editor/render/index.ts` exports `createRenderer(editor,stage,options)` returning RenderView; `editor/export/index.ts` exports `createExporter(editor,view,options)` returning ExportService; `editor/layout/index.ts` exports `applyLayout(doc)` to mutate an isolated candidate and settle layout/constraints. Publish other helpers through these entry points. DOM renderer and export consume the same measured scene, wait for fonts/images. Licensed CanvasKit may be used through a fresh wrapper for boolean/flatten operations. No UI imports.
- C: `editor/ui/index.ts` exports `mountWorkspace(root,services,options)` returning WorkspaceHandle; creates DOM including stage and layers/assets/inspector/toolbar. Parent creates mount services before renderer: call mountWorkspace with view/export proxies or split `createWorkspaceRoot(root,options)` returning stage then mountWorkspace; coordinate this explicit stage handoff with parent. `editor/interaction/**` belongs to C. All mutation via A transactions/commands and D service. Input editing uses native/browser semantic text support with IME, range formatting, grouped local history and transaction cancellation. No render/export reimplementation in UI.
- D: `editor/components/index.ts` exports `createComponentService(editor)` and `reconcileComponents(before,draft)`; `editor/styles/index.ts` exports `createStyleService(editor)` and `reconcileStyles(before,draft)`; `editor/assets/index.ts` exports local asset/library services. Component run(action,args) owns a single transaction, supports an optional existing nested transaction (no extra events). Return selection and IDs. All12componentactions and library compatibility required. Styles and component source propagation run in parent-supplied Editor reconciliation hooks.
- E: `editor/formats/index.ts` exports `importCanvasJson`, `exportCanvasJson`, `importHtml(html,options)`, `exportHtml(doc,pageId,ids,options)`, `importSvg(text,options)`; adapters retain known extension fields and opaque metadata. `editor/mcp/defs.ts` exports TOOLS (array schema records) and LvMcpToolName type if needed; `editor/mcp/index.ts` exports `installLvMcp(editor,view,options)` returning tools(), handleToolCall(),endSession(),dispose(). Parent injects services in options so MCP shares components/commands/export rather than reproducing logic. All19schemas and public behavior recorded in behavior contract. Build CLI imports new defs after integration.
- Parent: root `editor/contracts.ts`, `editor/index.ts` facade; host/build/config/docs/provenance; remove inherited implementation only when all replacement paths connected.

Use named exports above, no cross-lane root-file edits. Consumers can add narrowly typed extensions to interfaces only through parent coordination. Compatibility Data records retain unknown fields; validation is required and must not be bypassed using casts. Notify dependent lanes of additional helper signatures.

## Host behavior

mountEditor(root,{document,title,subtitle,faces,defaultFamily,fallbacks,wasmUrl,exportFile}) async returns editor,view,export,fonts,commands,session,editingText(),highlightAgent(),edit(),editPath(),ready(),set(),flush(),destroy(). Optional generic adapters remain explicit hooks. No paid/cloud service is configured in the current host.

Editor on() emits changes plus operation:{id,label} for durable logical edits; host computes immutable diff, sends operation.id as group. It also consumes selection,viewport,page events. Host overrides undoStep/redoStep; undo.blocked prevents history during active user sessions. Read-only MCP remains available. Remote receive must preserve valid active text editing, prune deleted selection and emit projection without creating a new local durable edit.

Geometry uses WORLD x/y/width/height as unrotated box, affine orientation matrix around box center with zero e/f, derived corners/inverse/rotation/flips. Path endpoints and controls are WORLD points; host CRDT normalizes them. ROOT id is root and root is frame self-parented. Viewport={vport:{width,height},vbox:{x,y,width,height},zoom}. No parent-local geometry switch or gratuitous file/protocol bump.

Measured view={settled,measure,computedStyle,screenshot,element}. measure entries x/y/w/h/scrollW/scrollH/clippedText/overflowParent plus optional fallback/image failure. screenshot returns raw base64 and mimeType, optional slices. Slice mode1568height/120overlap; overview max~340000pixels. Rendered SVG uses browser-measured text line positions. Layer PNG/JPG/WebP/SVG/PDF; PDF raster-backed. Native save/cancel/errors awaited. Guides/selection overlays excluded from export.

DOM interoperability: .file-name b,#stage,.ltabs button Assets,.layers[role=tree],.row[data-id],.page-row[data-id],.atile,#right,.design > section,#tools,[data-tool],[data-key],textarea[aria-label="Text editor"],.find-bar[role=search],#editor.collapsed. Parent may update actual old script interactions after implementation but must preserve behavior.

## Acceptance choices

All active host functionality, persisted records and generic public helper contracts are in scope; optional providers remain injectable and are not represented as available hosted services. Numeric geometry invariant tolerance1e-6; measured CSS bounds tolerance0.5px for identical fonts/viewport; text line breaks and content exact; raster antialiasing assessed separately without hiding missing geometry/style. Intentional defect fixes require explicit logged compatibility exception and evidence, not silent behavior changes.

Implementation phase: no regression authoring/running until all mandatory rows statically implemented, wired, and build/type checks pass. No stub, disabled required option, old fallback, or truthy placeholder qualifies. Parent final gate then new regression suite and real Electron/TLS/MCP/package evidence.
