### Vector authoring additions (2026-11-05)

`write_svg(svg,target,position)` imports editable native layers through the same SVG importer as paste; unsupported features remain pictures and return warnings. Input is capped at 200,000 characters, 2,000 layers and 10,000 path segments. Unlike `write_html` inline SVG, this supports subsequent node editing.

`get_path(id)` returns native segments with indices, fill rule, editable status, world coordinate space and current revision. `edit_path(id,revision,action,...)` accepts move_nodes, insert_node, delete_nodes, set_handle, convert_node, close and open. Close/open may specify a node index to target its contour; without an index each contour is handled independently. A stale revision or invalid node rejects the whole operation. Read again after edits because indices may change. Locked or hidden paths are protected.

`boolean(ids,operation,revision)` accepts ordered distinct vector roots without ancestor overlap. Operations are union/subtract/intersect/exclude/flatten; subtraction removes each subsequent operand from the first. Source layers remain children in operand order. Flatten accepts one or more inputs, produces a native editable path using the first source appearance, and preserves its hidden sources as siblings linked by flattenSourceIds. Use the new path ID for get_path/edit_path. A document/page change during asynchronous computation rejects the result. `outline(ids,kind,revision)` delegates stroke/text outline conversion to the shared commands, preserving the source and agent-owned undo.

All new mutations are standalone atomic operations; they are intentionally excluded from `batch` to avoid nested transactions and asynchronous mutation inside a synchronous batch. `get_guide(vector)` describes the workflow and limitations.

`image(id,action,revision)` exposes local background removal and restoration through the shared image service. Actions are `remove_background` and `restore`; the removal preserves the original and supports cancellation before commit. The tool records agent ownership for undo. `get_guide(image)` explains the local workflow and segmentation limitations.
